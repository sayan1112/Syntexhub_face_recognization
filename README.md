# Face Recognition Project

## Run

Use the system Python 3.14 interpreter with the project's virtual environment packages available:

```bash
cd /Users/sayandutta/face-recognization-project
/Library/Frameworks/Python.framework/Versions/3.14/bin/python3 recognize_faces.py
```

To register a new face:

```bash
cd /Users/sayandutta/face-recognization-project
/Library/Frameworks/Python.framework/Versions/3.14/bin/python3 register_face.py
```
